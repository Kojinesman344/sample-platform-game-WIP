# Testing Guide for Sample Platform Game

## Game Testing Instructions
1. **Setup:**  
   - Ensure that your system meets the minimum requirements.
   - Install the latest version of the game from the repository.

2. **Launching the Game:**  
   - Open the executable file located in the `bin` folder.

3. **Game Modes:**  
   - Select a game mode from the main menu to begin testing.

4. **Testing Objectives:**  
   - Verify that all game features work as intended, including character movement, enemy behavior, and level progression.
   - Report any bugs or glitches encountered during gameplay.

## Controls
- **W/A/S/D**: Move character up, left, down, right.
- **Space**: Jump
- **Left Mouse Button**: Attack
- **Esc**: Pause Menu

## Troubleshooting Guide
### Common Issues
- **Game Won't Start:**  
   - Ensure your graphics drivers are updated.
   - Check that your system meets all requirements listed in the setup.

- **Lag during Gameplay:**  
   - Lower the graphics settings in the options menu.
   - Close unnecessary applications running in the background.

- **Controllers Not Responding:**  
   - Make sure your controller is connected properly.
   - Check for firmware updates for your controller.
